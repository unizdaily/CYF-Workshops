Q: What is the difference between a fork and cloned repository?
A: 
A fork makes your own copy of someone else's repository on GitHub (under your own account), so you can make changes without affecting the original project. It's linked to the original repo, and you can later submit your changes back via a pull request.
While a clone means downloading a copy of a repository (yours, a fork, or anyone else's) from GitHub onto your local computer, so you can work on it. Cloning doesn't create a new copy on GitHub, it just gives you a local, working version of a repo that already exists.

Remember to commit and push when you're finished!
