Consider the code in this program below:

```js
function calculateSum(a, b) {
  return a + b;
}

function logSum(a, b) {
  console.log(a + b);
}

const result1 = calculateSum(10, 32);
const result2 = logSum(10, 32);
```

a) what will `result1` evaluate to? Explain your answer.
A: `result1` is 42 because calculateSum` has a `return` statement that sends the value of `a + b` back out of the function, and that returned value (42) is what gets assigned to `result1`.

b) What will `result2` evaluate to? Explain your answer
A: `result2` is `undefined` because `logSum` only calls `console.log(a + b)`, which prints `42` to the console as a side effect, it has no `return` statement. Since the function doesn't explicitly return a value, JavaScript implicitly returns `undefined`, so that's what gets assigned to `result2`.

c) Try to summarise the main difference between `logSum` and `calculateSum`
A: `calculateSum` returns a value which is 42 that means the result of a + b is handed back to whatever called the function, so it can be stored in a variable (result1), passed into another function, used in a calculation, etc. The function produces a usable value. While `logSum` only outputs the value console.log(a + b) just prints 42 to the console as a side effect, for a human to look at — but the function itself has no return statement, so it hands back nothing (hence undefined). The rest of the program can't do anything with what logSum "did," because the value never actually leaves the function.
